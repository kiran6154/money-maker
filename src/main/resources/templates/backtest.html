🧪 Backtest

Backtest mode lets you drive the same LoginOrchestrator the live scheduler uses, but on demand instead of on a cron. There is intentionally no parallel "test login" code path.

Run mode

LIVE

app.mode=backtest — the live scheduler is disabled and you can drive LoginOrchestrator.ensureLoggedIn() from the button below. app.mode=live — the live scheduler runs (08:00 cron + 1-min heartbeat) and the manual login endpoint is not registered. Set app.mode=backtest in application.properties and restart to enable manual runs.

Manual login

idle

Active broker: ZERODHA. Calls POST /api/backtest/login, which delegates to LoginOrchestrator.ensureLoggedIn() — same code path the 08:00 cron uses.
